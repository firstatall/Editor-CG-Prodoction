# CG Footage — คลิปที่ 1 "จากก้าวแรก สู่ 20 ปีของ 'หมอดีแห่งแผ่นดิน'"

Motion CG สำหรับทีมตัดต่อ — ทำ **เฉพาะรายการที่สคริปต์ระบุ (Motiongraphic)** เท่านั้น
Super / Lower third / ข้อความบนจอ ทีมตัดต่อทำเองตามคอลัมน์ "ข้อความบนจอ (Super)" ในสคริปต์

## สเปกไฟล์

| | |
|---|---|
| ขนาด / เฟรมเรต | 1920×1080 · 25 fps |
| `.mov` | QuickTime **Animation (RLE) + Alpha** พื้นโปร่งใส วางทับ Footage ได้ทันที |
| `.mp4` | H.264 พื้นทึบ |
| สี Motif | เขียว `#1FB57A` · เขียวเรือง `#7CF2B8` · เขียวเข้ม `#0B3B36` |

**Premiere:** ถ้าขอบ Glow ดูเป็นสีดำ ให้คลิกขวาที่คลิป → Modify → Interpret Footage → Alpha: *Straight*
**เคล็ดลับ:** ถ้าวางทับภาพสว่าง ลอง Blend Mode *Screen* ให้ Glow กลืนภาพ

## หมายเหตุ

- **ช่วง 1 Reverse ย้อนเวลา** และ **ช่วง 6 Match-cut** สคริปต์ระบุเป็น Footage ลูกค้า / ถ่ายจริง จึงไม่ได้ทำเป็น CG
- จุดแสงบนแผนที่วางตามตำแหน่งจังหวัดโดยประมาณ (ภาพประกอบ ไม่ใช่ข้อมูลจริง)
